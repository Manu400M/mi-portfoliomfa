# Ilustraciones conceptuales originales

Tres ilustraciones vectoriales creadas para este portfolio el 17 de noviembre de 2026. Son composiciones originales de formas geométricas, texto y líneas; no incluyen elementos gráficos descargados, logos ni fragmentos de modelos o documentos de empresa.

| Archivo | Tema | Tamaño |
| --- | --- | --- |
| `cad-ifc.svg` | Conjunto esquemático en vista explosionada y revisión conceptual de geometría y propiedades. | `viewBox` 1200 × 720 |
| `seguimiento.svg` | Tabla y vista abstractas de seguimiento documental con estados ilustrativos, sin identificadores ni cifras. | `viewBox` 1200 × 720 |
| `propuestas.svg` | Entradas documentales y borrador técnico sujeto a revisión; no representa una plantilla corporativa. | `viewBox` 1200 × 720 |

Todas las imágenes incorporan título y descripción accesibles, tipografía de sistema y una paleta azul oscuro/verde azulado coherente con el portfolio. Los estados mostrados son ejemplos conceptuales. No son capturas de las aplicaciones ni evidencia de funcionalidades implantadas; no representan datos, registros, modelos, procesos privados, clientes u ofertas reales. La dimensión vectorial permite redimensionarlas sin pérdida de resolución.
