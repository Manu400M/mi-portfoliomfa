# Ilustraciones técnicas originales

Cuatro ilustraciones vectoriales creadas para este portfolio el 17 de noviembre de 2026. Son composiciones originales de geometría, texto y líneas, con una paleta azul marino y verde azulado. No utilizan fotografías, logos de proyectos, capturas de aplicaciones, modelos, plantillas, arquitectura de software ni información interna de empresa.

| Archivo | Representación | Tamaño |
| --- | --- | --- |
| `verificacion.svg` | Conjunto industrial axonométrico inventado, relacionado con modelo CAD, plano, lista de materiales y requisitos para ilustrar el contraste entre fuentes. | `viewBox` 1200 × 720 |
| `cad-ifc.svg` | Geometría y propiedades sintéticas junto a un recorrido conceptual de origen, conciliación, incidencias y verificación; la revisión humana aparece explícitamente. | `viewBox` 1200 × 720 |
| `seguimiento.svg` | Estados ficticios de revisión documental, con derivación a observación o aceptación y retorno a revisión. No representa un procedimiento corporativo. | `viewBox` 1200 × 720 |
| `propuestas.svg` | Solicitud y mediciones abstractas, validación previa y generación de un borrador sujeto a revisión humana. No reproduce una oferta ni una plantilla comercial. | `viewBox` 1200 × 720 |

Cada SVG incluye `role="img"`, título y descripción accesibles, y una nota visible de «Ilustración conceptual · datos ficticios» adaptada al tema. La tipografía de los rótulos tiene entre 28 y 40 unidades en el lienzo original. Las páginas que emplean estas imágenes deben conservar un texto equivalente legible en móvil y no presentarlas como evidencia de funcionalidades terminadas o desplegadas.

Las formas, correspondencias y estados son inventados para explicar métodos generales. No aparecen nombres de clientes, identificadores, métricas, archivos ni registros reales. Las imágenes no acreditan participación en una instalación o proyecto concreto.
