Los iconos Autodesk se obtuvieron de las páginas oficiales de los productos, que los sirven desde su CDN Contentful: https://www.autodesk.com/products/inventor/overview y https://www.autodesk.com/products/navisworks/overview.

Los recursos Simple Icons proceden de la versión 11.15.0 del catálogo (https://github.com/simple-icons/simple-icons/tree/11.15.0); se añade únicamente el color de marca declarado en el propio catálogo (Ansys #FFB71B, Dassault Systèmes #005386, Python #3776AB, Microsoft Excel #217346 y Power BI #F2C811). Las licencias y guías de cada marca se recogen en https://cdn.jsdelivr.net/npm/simple-icons@11.15.0/_data/simple-icons.json.

`dassault-systemes.svg` identifica al fabricante común de CATIA y 3DEXPERIENCE; no es un icono específico de cada producto. SolidWorks utiliza su propio logotipo oficial en `solidworks.svg`. `ansys.svg` identifica la familia Ansys y puede acompañar Mechanical, Workbench y LS-DYNA. `excel.svg` identifica Excel, también cuando se menciona VBA; VBA no se representa como marca independiente. El formato IFC y los esquemas IDS se muestran como texto: el símbolo IfcOpenShell corresponde exclusivamente a la herramienta.
